# Активное обучение для распознавания дорожных знаков GTSRB

Учебный проект по дисциплине «Фундаментальные и перспективные концепции искусственного интеллекта». В проекте реализовано активное обучение сверточной нейронной сети для классификации дорожных знаков из набора **German Traffic Sign Recognition Benchmark (GTSRB)**.

GTSRB содержит изображения 43 классов дорожных знаков. В обычном обучении все изображения должны быть размечены заранее. В активном обучении модель начинает с небольшого размеченного множества и самостоятельно выбирает изображения, разметка которых должна принести наибольшую пользу.

## Цель проекта

Цель эксперимента — сравнить стратегии активного выбора изображений и определить, позволяют ли они получить более высокое качество при одинаковом бюджете разметки по сравнению со случайной выборкой.

В проекте сравниваются следующие стратегии:

- `entropy` — выбор изображений с максимальной энтропией распределения вероятностей;
- `margin` — выбор изображений с минимальной разницей между двумя наиболее вероятными классами;
- `least_confidence` — выбор изображений с наименьшей максимальной вероятностью класса;
- `random` — случайный выбор, используемый как контрольная стратегия.

## Как работает активное обучение

Обучающая часть GTSRB разделяется на три множества:

- `L` — размеченные изображения, доступные для обучения;
- `U` — пул изображений, которые считаются неразмеченными;
- `validation` — фиксированная выборка для промежуточной оценки модели.

На каждом раунде выполняются следующие действия:

1. Создается новая CNN и обучается только на текущем множестве `L`.
2. Рассчитываются `accuracy` и `macro-F1` на validation и test.
3. Модель получает предсказания для всех изображений из пула `U`.
4. Выбранная стратегия рассчитывает информативность каждого изображения.
5. Из пула запрашивается пакет из `query_size` наиболее информативных объектов.
6. Метки выбранных изображений считываются из GTSRB, имитируя ответ эксперта-оракула.
7. Выбранные объекты переносятся из `U` в `L`, после чего начинается следующий раунд.

Истинные метки пула не используются при вычислении неопределенности. Они становятся доступны алгоритму только после выбора конкретных индексов.

## Стратегии выбора

Пусть `p(c | x)` — предсказанная моделью вероятность класса `c` для изображения `x`.

### Entropy

```text
H(x) = -Σ p(c | x) · log(p(c | x))
```

Большая энтропия означает, что вероятность распределена между несколькими классами и модель не уверена в ответе.

### Margin sampling

```text
M(x) = p₁(x) - p₂(x)
```

`p₁` и `p₂` — две наибольшие вероятности. Чем меньше разница между ними, тем сложнее модели выбрать один из двух классов.

### Least confidence

```text
LC(x) = 1 - max p(c | x)
```

Чем меньше максимальная вероятность, тем выше приоритет изображения для разметки.

### Random sampling

Изображения выбираются случайно. Эта стратегия нужна как базовая линия: активная стратегия полезна только тогда, когда при одинаковом количестве размеченных объектов она стабильно превосходит `random`.

## Архитектура нейронной сети

В проекте используется компактная `TrafficSignCNN`, которую можно многократно переобучать на каждом раунде активного обучения.

| Часть модели | Состав | Результат для входа 48 × 48 |
|---|---|---|
| Сверточный блок 1 | две `Conv2d`, `BatchNorm`, `ReLU`, `MaxPool` | 32 × 24 × 24 |
| Сверточный блок 2 | две `Conv2d`, `BatchNorm`, `ReLU`, `MaxPool` | 64 × 12 × 12 |
| Сверточный блок 3 | две `Conv2d`, `BatchNorm`, `ReLU`, `MaxPool` | 128 × 6 × 6 |
| Классификатор | `Flatten`, `Linear(256)`, `ReLU`, `Dropout(0.35)` | вектор признаков |
| Выход | `Linear(43)` | логиты 43 классов |

Размер входа полносвязного слоя рассчитывается из аргумента `--image-size`. В модели нет проблемного варианта `AdaptiveAvgPool2d`, поэтому она работает на CPU, NVIDIA CUDA и Apple MPS.

Для оптимизации используется `AdamW`, а функция потерь — многоклассовая cross-entropy. На каждом раунде модель обучается заново. Это делает сравнение стратегий честнее, поскольку результат не зависит от накопленного состояния оптимизатора предыдущего раунда.

## Подготовка изображений

Обучающие изображения:

- масштабируются до `48 × 48`;
- поворачиваются в пределах 10 градусов;
- получают небольшой случайный сдвиг и изменение масштаба;
- получают изменение яркости и контраста;
- преобразуются в тензор и нормализуются.

Горизонтальное отражение не применяется, поскольку оно может изменить смысл дорожного знака. Для validation, пула активного обучения и test используются только масштабирование, преобразование в тензор и нормализация. Поэтому оценка неопределенности остается детерминированной и не зависит от случайной аугментации.

## Основные части кода

### `RunConfig`

Dataclass содержит все параметры эксперимента. Перед запуском обучения конфигурация сохраняется в `run_config.json`, поэтому эксперимент можно воспроизвести.

### `TrafficSignCNN`

Описывает сверточную нейронную сеть. Размер последнего сверточного представления рассчитывается на основе `image_size`.

### `make_datasets()`

Создает три представления данных:

- `train_dataset` с аугментациями для обучения;
- `pool_dataset` без случайных преобразований для validation и выбора запросов;
- `test_dataset` для независимой итоговой оценки.

При обычном запуске используется `torchvision.datasets.GTSRB`. В режиме `--smoke-test` набор заменяется на `FakeData`, что позволяет проверить весь программный конвейер без загрузки GTSRB.

### `initial_pool_split()`

Выполняет стратифицированное формирование начального размеченного множества. Для каждого присутствующего класса выбирается до `initial_per_class` изображений. Остальные изображения переходят в неразмеченный пул.

### `train_model()`

Создает новую модель, DataLoader, оптимизатор `AdamW` и выполняет заданное количество эпох обучения на текущем размеченном множестве.

### `predict()` и `evaluate()`

`predict()` рассчитывает вероятности классов в режиме `torch.inference_mode()`. `evaluate()` преобразует вероятности в метки и вычисляет:

- `accuracy` — долю правильных ответов;
- `macro-F1` — среднее F1 по всем классам с одинаковым весом каждого класса.

`macro-F1` особенно важен для GTSRB, поскольку классы представлены неравномерно.

### `uncertainty_scores()` и `query_indices()`

`uncertainty_scores()` реализует формулы entropy, margin и least confidence. `query_indices()` сортирует объекты по информативности или выполняет случайный выбор для стратегии `random`.

### `run_strategy()`

Управляет полным циклом активного обучения для одной стратегии: обучение, оценка, запрос меток, расширение `L` и сохранение метрик.

### `main()`

Разбирает аргументы командной строки, выбирает вычислительное устройство, создает данные, последовательно запускает стратегии и сохраняет результаты.

## Запуск

### Проверка установки без GTSRB

```bash
python active_learning_gtsrb.py \
  --smoke-test \
  --strategies entropy random \
  --rounds 1 \
  --epochs 1 \
  --output-dir smoke_results
```

Результаты `FakeData` проверяют работоспособность программы, но не характеризуют качество распознавания дорожных знаков.

### Короткий запуск на GTSRB

Подходит для проверки перед полным экспериментом:

```bash
python active_learning_gtsrb.py \
  --data-dir data \
  --output-dir results_quick \
  --strategies entropy random \
  --rounds 2 \
  --epochs 2 \
  --initial-per-class 5 \
  --query-size 200 \
  --max-train-samples 5000 \
  --max-test-samples 2000
```

### Полный эксперимент

```bash
python active_learning_gtsrb.py \
  --data-dir data \
  --output-dir results
```

По умолчанию сравниваются `entropy`, `margin` и `random`. Для каждой стратегии выполняется начальный раунд и восемь активных запросов, то есть всего обучается 27 отдельных моделей по 8 эпох. Полный эксперимент может выполняться продолжительное время.

### Запуск одной стратегии

```bash
python active_learning_gtsrb.py \
  --data-dir data \
  --output-dir results_entropy \
  --strategies entropy \
  --rounds 8 \
  --epochs 8
```

## Аргументы командной строки

| Аргумент | Значение по умолчанию | Назначение |
|---|---:|---|
| `--data-dir` | `data` | каталог для загрузки GTSRB |
| `--output-dir` | `results` | каталог результатов |
| `--strategies` | `entropy margin random` | список сравниваемых стратегий |
| `--rounds` | `8` | количество активных запросов после начального раунда |
| `--query-size` | `600` | количество изображений в одном запросе |
| `--initial-per-class` | `20` | начальное число размеченных объектов каждого класса |
| `--epochs` | `8` | число эпох обучения модели на каждом раунде |
| `--batch-size` | `128` | размер mini-batch |
| `--learning-rate` | `0.001` | скорость обучения AdamW |
| `--weight-decay` | `0.0001` | L2-регуляризация AdamW |
| `--validation-fraction` | `0.1` | доля train, выделяемая для validation |
| `--seed` | `42` | seed генераторов Python, NumPy и PyTorch |
| `--num-workers` | `2` | число процессов загрузки данных |
| `--image-size` | `48` | ширина и высота изображения |
| `--max-train-samples` | без ограничения | ограничение train для пробного запуска |
| `--max-test-samples` | без ограничения | ограничение test для пробного запуска |
| `--smoke-test` | выключен | использование `FakeData` вместо GTSRB |

Справку по всем аргументам можно получить командой:

```bash
python active_learning_gtsrb.py --help
```

## Выходные файлы

После успешного запуска в `output-dir` создаются:

| Файл | Содержание |
|---|---|
| `run_config.json` | параметры конкретного запуска |
| `metrics.csv` | метрики каждой стратегии по раундам |
| `selected_samples.csv` | индексы и классы объектов, запрошенных у оракула |
| `learning_curve.png` | график зависимости test accuracy от числа размеченных изображений |

Основные столбцы `metrics.csv`:

- `strategy` — стратегия выбора;
- `round` — номер раунда, где `0` является начальным обучением;
- `labeled_count` — размер размеченного множества;
- `validation_accuracy` и `validation_macro_f1` — качество на validation;
- `test_accuracy` и `test_macro_f1` — качество на test.

## Выбор компьютера и операционной системы

Наиболее удобный вариант для полного эксперимента — компьютер с NVIDIA GPU и CUDA:

- NVIDIA RTX 3060/4060 или мощнее;
- не менее 8 ГБ видеопамяти;
- 16 ГБ оперативной памяти, желательно 32 ГБ;
- 5 ГБ свободного места с запасом для окружения, датасета и результатов;
- Ubuntu 22.04/24.04 или Windows 11.

Linux обычно проще для воспроизводимых ML-экспериментов и удаленных серверов. Windows также подходит при корректно установленной версии PyTorch с CUDA.

Mac с процессором Apple Silicon поддерживается через MPS. Код проверен на `device=mps`. Для учебного запуска MacBook с M1/M2/M3/M4 и 16 ГБ объединенной памяти подходит, но серия из 27 обучений обычно будет выполняться дольше, чем на современной NVIDIA GPU.

CPU тоже поддерживается, однако полный эксперимент может занять много времени. Для проверки на CPU следует сначала использовать короткую конфигурацию с `--max-train-samples`, небольшим числом раундов и эпох.

Устройство выбирается автоматически в порядке:

```text
CUDA → Apple MPS → CPU
```

## Воспроизводимость эксперимента

Проект фиксирует генераторы Python, NumPy и PyTorch через `--seed`. Для более надежного вывода рекомендуется выполнить эксперимент несколько раз, например с seed `42`, `43`, `44`, `45` и `46`, а затем сравнить среднее значение и стандартное отклонение метрик.

Пример повторного запуска:

```bash
python active_learning_gtsrb.py --seed 43 --output-dir results_seed_43
```

Каждая стратегия внутри одного запуска получает одинаковое начальное разбиение `L`, `U` и validation.

## Возможные проблемы

### `CERTIFICATE_VERIFY_FAILED`

Проект использует хранилище корневых сертификатов `certifi`. Обновите зависимости:

```bash
pip install -r requirements.txt
```

Проверка подлинности HTTPS не отключается.

### Ошибка или зависание DataLoader

На некоторых системах помогает отключение дополнительных процессов:

```bash
python active_learning_gtsrb.py --num-workers 0
```

### Недостаточно памяти

Уменьшите размер batch:

```bash
python active_learning_gtsrb.py --batch-size 64
```

При необходимости также уменьшите `--image-size`, но значение должно быть не меньше 8.

### Очень долгий запуск

Сначала ограничьте объем данных и количество переобучений:

```bash
python active_learning_gtsrb.py \
  --max-train-samples 5000 \
  --max-test-samples 2000 \
  --rounds 2 \
  --epochs 2
```
